## featured projects

### [RetailFlow AI — Retail Store Analytics using CCTV](https://github.com/Jee0512/retailflow-ai)

A computer vision analytics platform that processes supermarket CCTV footage to track customer footfall, measure dwell time per zone, filter staff from shopper metrics, and generate operational reports — all without facial recognition or biometric identification.

**Key features**
- YOLOv8 person detection with ByteTrack centroid tracking
- Footfall counting and zone dwell analysis with heatmap accumulation
- Staff filtering via uniform color detection
- Interactive Streamlit dashboard with KPI scorecards and charts
- PDF report generation and SQLite-based authentication

**Tech:** Python · YOLOv8 · OpenCV · Streamlit · Plotly · Pandas/NumPy · fpdf2 · SQLite
